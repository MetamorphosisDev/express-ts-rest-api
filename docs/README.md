## Topik Rencana

Checklist catatan belajar yang bisa ditambahkan ke sini:

- [ ] Express 5 vs Express 4: perbedaan syntax `path-to-regexp`, API yang dihapus/rename
- [ ] Drizzle ORM: `drizzle-kit push` vs `migrate`, definisi relasi
- [ ] Neon Serverless: koneksi HTTP vs TCP (perbedaan latency & usage)
- [ ] Error handling terpusat (middleware `(err, req, res, next)`)
- [ ] Validasi input request dengan zod
- [ ] Testing API dengan vitest + supertest
- [ ] Deployment (Docker / Vercel / Railway)
